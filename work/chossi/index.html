ChoSSI

Case study

Problem → decisions → product.

01 · Context / problem

The challenge

The opportunity is bigger than a marketing page. A communication academy needs to explain programs clearly, create confidence before registration, and make day-to-day class operations manageable for the team behind it.

02 · What I did

The approach

I structured the experience around programs, upcoming classes, mentor credibility, alumni proof, registration, corporate inquiries, and a private admin system. The product is being refined toward a modern learning experience with a practical operations layer behind it.

03 · Key decisions

What shaped the system

  • Public information architecture for programs, classes, mentor, alumni, corporate, insights, FAQ, and legal pages
  • Registration flow designed around class state, validation, reference IDs, and operational follow-up
  • Private admin direction for programs, classes, registrations, leads, media, articles, FAQs, and site settings
  • Responsive experience built around clear next-class actions instead of decorative content

04 · Final product / result

Where it lands

A connected public + admin product direction where content, classes, registration, and operations live in one system. The project remains in active refinement, so this portfolio avoids freezing unfinished interface screenshots.
